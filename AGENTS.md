# Workspace Rules

## Pre-Change Approval Protocol
Before making ANY changes to the codebase (editing existing files or creating new code files):
1. **Explain the Issue**: Clearly diagnose and describe what the issue or requirement is.
2. **Explain the Proposed Solution**: Outline the exact steps, files, and logic changes you plan to apply.
3. **Wait for User Approval**: Do NOT modify or write code until the user explicitly reviews and agrees to the proposed solution.
